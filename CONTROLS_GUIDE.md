# 🎮 Controls Guide

## Main Challenge Simulation Controls

### 🖥️ **WASD Keyboard Controls** (Laptop)

**Movement:**
- **W** - Move Forward
- **S** - Move Backward  
- **A** - Turn Left
- **D** - Turn Right

**Arm Control:**
- **Q** - Arm Up
- **E** - Arm Down

**Gripper Control:**
- **Z** - Close Gripper
- **X** - Open Gripper

### 🎮 **PS5 Controller** (On-Screen)

**Sticks:**
- **Left Stick** - Click and drag to move forward/backward
- **Right Stick** - Click and drag to turn left/right

**Buttons:**
- **△ (Triangle)** - Arm Up
- **✕ (Cross)** - Arm Down
- **□ (Square)** - Close Gripper
- **○ (Circle)** - Open Gripper

### 📍 **Field Layout**

The Main Challenge field matches the official NRL Battle of Charges layout:

**12x12 ft Field (144 in x 144 in):**
- **Foam Tiles:** 36 tiles (6x6 grid), each 24in x 24in
- **Wood Frame:** Surrounds the entire field

**Zones:**
- **Charge Station:** Center of field
  - Top half: Red (Red team)
  - Bottom half: Blue (Blue team)
  
- **Source Zones:**
  - Top-right corner: Blue team source zone
  - Bottom-right corner: Red team source zone
  
- **Drop Zones:**
  - Top-left corner: Red team drop zone (triangular)
  - Bottom-right corner: Blue team drop zone (triangular)
  
- **Robot Start Zones:**
  - Top-center: Red team start zone
  - Bottom-center: Blue team start zone

**Pre-placed CHARGES:**
- Located along field edges
- Color-coded by team (red/blue)

### 🤖 **Using Controls**

1. **Start Main Challenge Simulation:**
   - Click "Main Challenge" button
   - Go to Simulation tab

2. **Choose Control Method:**
   - Use **WASD keys** on your laptop keyboard
   - OR use the **PS5 controller** on screen

3. **Control Robot:**
   - Press and hold movement keys (W/A/S/D)
   - Press buttons for arm/gripper actions
   - Robot responds in real-time

4. **Strategy:**
   - View strategy recommendations on the right panel
   - See real-time predictions
   - Monitor CHARGES scored and time remaining

### 💡 **Tips**

- **For Testing:** Use WASD keys - easier for quick testing
- **For Competition Practice:** Use PS5 controller - matches real competition
- **Movement:** Hold keys for continuous movement
- **Precision:** Release keys for precise positioning
- **Strategy:** Follow AI recommendations for optimal scoring

### 🔧 **Troubleshooting**

**Keys not working:**
- Make sure Main Challenge simulation is running
- Click on the simulation canvas first
- Check browser console for errors

**PS5 controller not working:**
- Click and drag sticks (don't just click)
- Make sure you're in Main Challenge mode
- Try refreshing the page

**Robot not moving:**
- Check time remaining (simulation may have ended)
- Verify simulation is running
- Check network connection to server
